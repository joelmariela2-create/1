---
name: Store product views
description: User preference for preserving the store's default product grid while supporting horizontal browsing.
---

Keep the product catalog's existing vertical grid as the default view, and offer horizontal carousel browsing as a separate option. Product cards should remain portrait-oriented in both views.

**Why:** The user asked to add horizontal browsing without changing or disrupting the current vertical store layout.

**How to apply:** When changing product discovery or responsive catalog layouts, preserve the grid as the initial view and keep horizontal swiping optional.
